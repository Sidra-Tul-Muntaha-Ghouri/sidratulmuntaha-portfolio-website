## 📁 Featured Projects

### 1. MCC Panel — DOL & VFD Starters

An LV motor control panel designed for applications requiring both **Direct-On-Line (DOL)** and **Variable Frequency Drive (VFD)** motor starting.

The project demonstrates:

- Motor starter circuit design
- DOL and VFD control logic
- Protection and switching device selection
- Control circuit development
- Electrical schematic documentation
- Panel layout considerations

---

### 2. MDB — SIVACON S8

An LV Main Distribution Board designed using the **Siemens SIVACON S8** system.

The project focuses on:

- LV power distribution
- Incomer and outgoing feeder configuration
- Protection device selection
- Busbar arrangement
- Form of separation
- Panel configuration
- Electrical documentation

---

### 3. SMDB — PowerLine PLUS M

A **16-way Sub-Main Distribution Board** designed using the PowerLine PLUS M enclosure system.

The project demonstrates practical LV distribution-board design, including:

- Incoming supply arrangement
- Outgoing feeder configuration
- Protection devices
- Component selection
- Enclosure configuration
- Electrical documentation
